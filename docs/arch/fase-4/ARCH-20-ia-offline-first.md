# ARCH #20 — IA offline-first (runtime determinístico)

**Fase:** 4 · **Status:** vigente

## Decisão
Geração 100% determinística no runtime (zero LLM no caminho quente); IA = autoria offline (batch, revisão humana). PAR-Q em SQL. Substitui 'LLM ao vivo' (arquivado).
