# ARCH #13 — Navigation Compose Android-only

**Fase:** 4 · **Status:** vigente

## Decisão
Jetpack Navigation no androidApp, rotas type-safe. VM de orquestração (SplashViewModel) vive no app (topo da pirâmide), não na feature.
