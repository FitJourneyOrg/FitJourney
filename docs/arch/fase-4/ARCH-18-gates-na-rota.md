# ARCH #18 — Gates de geração na rota

**Fase:** 4 · **Status:** vigente

## Decisão
A rota cruza entitlement + saúde + geração (features não se conhecem; a rota junta). Débito: pulável se surgir 2º caller → mover p/ service.
